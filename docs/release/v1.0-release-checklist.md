# TaskFlow v1.0 Release Checklist

This release checklist defines the formal quality and operational gates required to sign off on **TaskFlow v1.0**.

Every item is classified as either:

- **AUTOMATED / LOCAL**: Verified automatically in local development or CI.
- **REQUIRES OPERATOR / INFRASTRUCTURE**: Requires deployment to human-managed cloud infrastructure.
